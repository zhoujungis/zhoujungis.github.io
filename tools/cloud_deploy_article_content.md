# 国内外云部署全攻略：国内云、海外 VPS 与 Cloudflare 免费全家桶怎么选

![数据中心](https://images.unsplash.com/photo-1544197150-b99a580bb7a8?w=1200&q=80&auto=format&fit=crop)

> 2026 年，把一个项目部署到线上，选择比以往任何时候都多：国内三大云厂商价格战打得火热、海外性价比 VPS 遍地开花、Cloudflare 更是把"免费"做到了极致。这篇文章把国内云、海外云、边缘平台三条路线放在一起对比，帮你找到最适合自己场景的部署方案。

## 为什么部署选择越来越复杂？

前几年"上云"基本就等于买台云服务器（IaaS），阿里云、腾讯云、AWS 三选一完事。但发展到现在，部署路径已经分化为**三条截然不同的路线**：

| 路线 | 代表 | 形态 | 核心特点 |
| --- | --- | --- | --- |
| 国内云服务器 | 阿里云/腾讯云/华为云 | IaaS 云主机 | 国内访问快、需要 ICP 备案、带宽贵 |
| 海外云 | AWS/Azure/GCP + Vultr/Hetzner | IaaS/PaaS | 免备案、全球节点、按美元计费、国内延迟不稳 |
| 边缘平台 | Cloudflare Pages/Workers | 静态托管+Serverless | 免费额度惊人、全球 CDN、几乎零运维 |

摆在面前的不是"哪家好"，而是**哪条路线更贴合你的业务形态**。下面逐一拆解。

## 一、国内云：卷出天际的价格战

![团队协作](https://images.unsplash.com/photo-1519389950473-47ba0277781c?w=1200&q=80&auto=format&fit=crop)

据 IDC 数据，2025 年中国公有云 IaaS 市场规模已突破 4000 亿元，阿里云、腾讯云、华为云稳居前三。2026 年这场竞争直接卷成了"价格战"：入门级配置被压到几十元一年。

### 当前主流活动价（2026 年中参考）

| 配置 | 阿里云 | 腾讯云 | 华为云 |
| --- | --- | --- | --- |
| 2核2G | 轻量 38-68元/年；ECS "99计划" 99元/年（续费同价） | 轻量约 82-99元/年；CVM S5 199元/年 | Flexus L 38-98元/年 |
| 2核4G | ECS u1 199元/年 | 蜂驰型 BF1 约 417元/年起 | Flexus L 约 165-199元/年 |
| 4核8G | ECS 约 955元/年 | 轻量 450元/年左右 | Flexus X 338元/年起 |

几点选型时务必注意的"潜规则"：

1. **首购价≠长期价**：很多低价仅限新用户，续费直接翻倍。优先选标注"续费同价"的活动（如阿里云 99 计划、腾讯云新老同享款）。
2. **带宽是隐形开销**：低价款常配 1-3M 固定带宽或"峰值带宽"，图站/下载站慎选。相对而言，阿里云轻量 200M 峰值不限流量的模式对突发流量最友好。
3. **必须 ICP 备案**：使用大陆节点必须备案，周期 7-20 个工作日。等不了就选香港/海外节点（免备案，但国内访问速度下降）。

### 国内云的独特优势

- **网络质量**：BGP 多线接入，国内各省市访问延迟低且稳定，这是海外 VPS 比不了的。
- **生态完善**：对象存储、CDN、短信、支付、AI 服务一站式集成，业务落地快。
- **支付与合规**：微信/支付宝直接付，发票、实名、监管一条龙，适合正规商用。

移动云、京东云、百度智能云也在用激进价格抢市场（移动云 2核4G 年付约 151 元、华为云 2核2G 38 元/年），预算敏感时值得对比，但生态和文档丰富度仍以三大厂为最。

## 二、海外云：免备案的自由与美元的标价

![分析数据](https://images.unsplash.com/photo-1460925895917-afdab827c52f?w=1200&q=80&auto=format&fit=crop)

海外部署的两大流派：**超大规模公有云**（AWS、Azure、GCP）和**开发者友好 VPS**（Vultr、DigitalOcean、Hetzner、Linode）。

### 大厂 vs VPS：定位完全不同

| 对比项 | AWS / Azure / GCP | Vultr / DO / Hetzner |
| --- | --- | --- |
| 定位 | 企业级全栈云平台 | 轻量级 IaaS，开发者友好 |
| 入门价格 | 按量计费，低配也要 $5-10/月，出站流量另算 | $2.5-6/月起步 |
| 免费额度 | 首年免费套餐（12 个月） | 充值返额度（Vultr $300 / DO $200） |
| 事项复杂度 | 高，账单容易失控（出站流量是"刺客"） | 低，按小时计费、价格透明 |
| 国内访问 | 普通国际线路，晚高峰丢包明显 | 同左，均无 CN2 GIA 优化线路 |

**关键数字（2026 年对比）**：同等 2核4G 配置，Hetzner CX22 约 €4.5/月（含 20TB 出站流量），DigitalOcean/Vultr 约 $24/月（含 1-3TB 流量），AWS EC2 则要贵上数倍且出站流量另计——这正是"同样的事，AWS 可能贵 10-50 倍"的由来。

### 各家强项速记

- **Hetzner**（德国）：欧洲性价比之王，20TB 免费出站流量近乎无限，EU 业务/GDPR 首选。
- **Vultr**：32 个全球机房，覆盖东京/首尔/新加坡等亚洲节点，按小时计费最灵活，还有 GPU 实例。
- **DigitalOcean**：文档教程业界标杆，App Platform 能"推代码即上线"，Kubernetes、托管数据库开箱即用。
- **AWS/Azure/GCP**：生态天花板，适合跨国业务、需要 S3/云数据库等托管组件的大项目。

海外 VPS 的痛点也很明确：**从国内访问普遍延迟 180-250ms**，晚高峰丢包；**支付需要国际信用卡**；部分平台封禁代理类用途。想要国内访问快，得选走 CN2 GIA 优化线路的专门商家（如搬瓦工），价格另说，且注意合规。

## 三、Cloudflare：免费额度界的"赛博活佛"

![笔记本电脑与代码](https://images.unsplash.com/photo-1531297484001-80022131f5a1?w=1200&q=80&auto=format&fit=crop)

如果说前两条路线还在花钱，Cloudflare 则把"白嫖"做到了极致——它早已不是单纯的 CDN 厂商，而是一个完整的边缘计算平台。**90% 的个人项目和中小型应用，免费版就够跑。**

### 免费额度速查表

| 产品 | 免费额度 | 用途 |
| --- | --- | --- |
| DNS + CDN | 无限带宽、不限流量 | 所有网站的加速底座，还能隐藏源站 IP |
| 免费 SSL | 自动签发与续签 | 秒变 HTTPS |
| WAF | 基础规则 + 5 条自定义规则 | 防爬虫、拦攻击、按国家屏蔽 |
| Pages | 无限带宽、500 次构建/月 | 静态网站/前端托管，全球 CDN |
| Workers | 10 万次请求/天 | Serverless API、反向代理、边缘逻辑 |
| R2 存储 | 10GB，**出站流量永久免费** | 图床、文件存储，对标 S3 |
| KV / D1 | 1GB KV / 5GB D1 | 缓存、会话、SQLite 数据库 |
| Tunnel | 无限流量 | 无公网 IP 也能内网穿透，比 frp 更稳 |
| Email Routing | 无限转发规则 | 免费自定义域名邮箱 |
| Workers AI | 每日免费 Token | 边缘跑大模型推理 |

### Cloudflare 的部署哲学：零成本分层架构

```
用户请求 → Cloudflare CDN（边缘节点）
              ↓
    Pages（前端静态资源）
              ↓
    Workers（API / 边缘逻辑）
              ↓
      KV + R2 + D1（存储全家桶）
              ↓
    Tunnel → 自有 VPS（重任务兜底）
```

举个真实场景：前端用 Pages、接口用 Workers、图片放 R2、数据存 D1、重任务通过 Tunnel 连回自己的一台 $5 VPS——**这套组合的月成本可以压到一台 VPS 的价格**。对比传统"云服务器+数据库+CDN+对象存储"动辄 $88-320/月的账单，优势是数量级的。

两个避坑点：免费版 Workers 单请求 CPU 时间限 10ms（await I/O 不算，别做 CPU 密集活）；免费额度会调整，上线前以官网定价页为准。付费从 Workers Paid $5/月起步，依然是地板价。

## 五、按场景给结论

**1. 个人博客 / 文档站 / 作品集（零预算优先）**
→ Cloudflare Pages + GitHub Pages。绑定 GitHub 仓库自动部署，无限带宽 + 全球 CDN，一分钱不花。追求极致简单选 GitHub Pages，追求速度与可扩展选 Cloudflare Pages。

**2. 正经国内项目 / 企业官网（需要备案）**
→ 国内三大云。预算敏感看活动价续费条款，稳定优先选阿里云 99 计划或腾讯云新老同享款；有华为生态/信创需求再考虑华为云。

**3. 出海业务 / 面向海外用户的站点**
→ Vultr（亚洲节点广）或 Hetzner（欧洲性价比）起步，规模大了再上 AWS。别忘了前面套一层 Cloudflare CDN。

**4. 个人项目但需要后端 API + 数据库**
→ 两条路：Cloudflare Workers + D1 + R2 全套边缘方案（最省钱）；或一台海外 VPS 全自己装（最灵活）。国内用户访问为主就选国内云的小配置。

**5. 已有服务器，想省钱又提速**
→ 不用换服务器，把域名接进 Cloudflare 免费版：CDN 加速 + WAF 防护 + 免费证书一条龙，还能隐藏源站 IP。

## 六、案例：本站的部署架构

![代码特写](https://images.unsplash.com/photo-1504384308090-c894fdcc538d?w=1200&q=80&auto=format&fit=crop)

拿本博客现身说法，用的正是"零成本 + 低成本"混合思路：

- **前端**：Vue 3 构建后推送到 GitHub Pages，静态托管免费、版本管理天然。
- **后端**：Django API 部署在 PythonAnywhere 免费档，够支撑文章接口和点赞。
- **图片**：走 Unsplash 远程图床，本地零存储成本。

它就是"没有服务器也能跑一个完整前后端项目"的活例子。如果哪天 PythonAnywhere 限额不够，下一步就是 Cloudflare Workers 换掉后端、R2 换掉图片——迁移路径也是现成的。这也正是本文想传达的：**部署方案不是一锤子买卖，先用免费/低成本方案跑起来，随业务增长按需演进，才是最务实的上云姿势。**

## 七、最后的避坑清单

1. **续费条款看仔细**——首购便宜续费翻倍是国内云最大的坑，认准"续费同价"。
2. **出站流量是隐形刺客**——AWS 等按 GB 计费，海量图片/下载业务算清楚账再上车；R2 和 Hetzner 则永远免费。
3. **免费试用记得关**——到期自动扣费是经典事故，设好账单告警和预算上限。
4. **数据一定要异地备份**——廉价 VPS 没有冗余承诺，`rsync`/`restic` 定期备份是底线。
5. **合规先行**——国内大陆节点必须备案，代理类用途注意服务商 TOS 和当地法律。

**祝大家都能用最合理的成本，把自己的项目稳稳地送上线。**
