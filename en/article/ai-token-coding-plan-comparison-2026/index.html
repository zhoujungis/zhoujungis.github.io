AI Token Plans and Coding Plans in 2026: 20+ Platforms from China and Abroad, Compared

2026-07-22 · 19 min · Stack Frame

Introduction: 2026 and the All-Out Subscription War

In the first half of 2026, AI platforms at home and abroad moved en masse into the “Token Plan / Coding Plan subscription” era. From Alibaba Model Studio to Baidu Qianfan, from Kimi to MiniMax, from the three state telecom carriers to ChatGPT, Claude and Gemini — nearly every vendor now sells a monthly or quarterly plan. With 20+ platforms and 50+ plans to choose from, how is a developer actually supposed to decide? This article works from the latest public pricing as of July 2026 and puts the Token Plans and Coding Plans of 20 mainstream AI platforms in China and overseas side by side — the most complete comparison anywhere.

1. What Exactly Are Token Plans and Coding Plans?

┌──────────────────────────────────────────┬──────────────────────────────────────────┐
│                       How the two subscription models differ                        │
├──────────────────────────────────────────┼──────────────────────────────────────────┤
│    Token Plan                            │    Coding Plan                           │
├──────────────────────────────────────────┼──────────────────────────────────────────┤
│ • General chat and reasoning quota       │ • Purpose-built for AI coding            │
│ • Metered by tokens consumed             │ • Metered by requests or agent tasks     │
│ • Fits: writing, analysis, translation   │ • Fits: completion, agents, refactoring  │
│ • Examples: Model Studio Token Plan      │ • Examples: Model Studio Coding Plan     │
│   MiniMax Token                          │   Zhipu Coding Plan                      │
│   StepFun Step Plan                      │   Cursor / Copilot                       │
└──────────────────────────────────────────┴──────────────────────────────────────────┘
Put simply: a Token Plan is a ration book for general AI use; a Coding Plan is a coupon book for programming. If you mostly use AI to write code, reach for a Coding Plan first. For general-purpose work, take the Token Plan.

10.2 Key Trends

  1. Coding Plans become table stakes: Alibaba, Zhipu, Baidu and Volcano all ship a dedicated Coding Plan, metered separately from the general Token Plan
  2. The carriers crash the party: China Telecom's ¥9.9/month token bundle drags pricing to the floor and forces the internet platforms to cut prices
  3. Open-source tools plus a subscription API becomes the mainstream pairing: OpenCode (70K stars) on top of a Model Studio or Zhipu Coding Plan outclasses closed-source IDEs on value
  4. Credits get unified: Qoder CN is first to share one Credits pool across IDE, CLI, Work and Mobile
  5. Free tiers keep expanding: Trae, CodeGeeX, iFlytek Lite and GLM-4 Flash are free forever, so the barrier to entry is zero
  6. Agent consumption far exceeds expectations: a single “hello” can burn 49,000 tokens, and heavy agent users can spend tens of millions of tokens a month
