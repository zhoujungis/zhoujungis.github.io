Chinese LLMs All Raised Prices. Where Does That Leave Regular Users?

Data cutoff: August 18, 2026. This article compares the web memberships, Coding Plans, and API entry points individual developers buy most often, not enterprise contract pricing. USD prices are included for cross-reference only; rough CNY conversion uses 1 USD ≈ 6.8 CNY and ignores taxes, payment-channel fees, and regional differences. Models, quotas, and rate limits can all change, so open the official page and confirm before you buy.

The short version

  • Around ¥50 a month and mostly writing code in China: pick GLM Lite. It is cheap, and both the Chinese tooling and the payment story are friendly, but it is a Coding Plan rather than a general-purpose API, and quotas refresh on a 5-hour and weekly basis.
  • About $10 a month and comfortable in a terminal: OpenCode Go is currently the most flexible coding entry point. It is not a model; it is a subscription that packs a curated set of models — GLM, Kimi, MiniMax, DeepSeek and others — into one plan. The trade-off is that every model burns quota at a different rate, so do not read it as “unlimited use of all models.”
  • Everyday office work, writing, search, images and code: ChatGPT Plus or Claude Pro is less hassle. Plus has the more complete tool integration; Claude Pro is more appealing for hard code and long-running tasks. Neither publishes a fixed monthly quota you can convert precisely into tokens.
  • Heavy text or code workloads: MiniMax Plus has the biggest headline quota and DeepSeek Flash still has a low unit price, but after DeepSeek's August price change it is no longer the unconditional cheapest. You only capture DeepSeek's cost advantage if you can reuse long stable prefixes and push work into off-peak hours.
  • Best single-shot success rate: Claude Opus 5 and GPT-5.6 Sol remain the top tier. Opus is better suited to deep code review and long-horizon execution; GPT has the more complete speed, tooling, and office ecosystem. Neither is a good fit as “a cheap unlimited API.”

DeepSeek: is it still cheap after the price hike?

DeepSeek is now closer to a low-cost API vendor than to a membership product with a defined monthly quota. V4 Flash and V4 Pro both offer 1M context, and cache hits, cache misses, and output are billed separately; that means a coding agent's real bill depends on three variables: whether the system prompt is stable, whether the context hits the cache, and whether requests land in peak or off-peak hours. The price list that took effect on August 17 separates the earlier promotional pricing from the official rate. Per million tokens, V4 Pro off-peak is $0.022 for cache-hit input, $0.66 for cache-miss input, and $1.98 for output; peak doubles all three. V4 Flash off-peak is $0.007, $0.22, and $0.66. The cache-hit price rose the most dramatically, but it was also unusually low to begin with; for a short Q&A app with no long-prefix reuse, what actually matters is cache-miss input and output. One community user repriced 4.02 billion tokens across 18,445 requests from July 19 to August 16 at the new rates: about $53.38 originally; about $130.48 with everything off-peak, about $168.53 averaged across the whole day, and about $260.95 with everything at peak. This is not an official promise, but it shows that “how much did the price go up” cannot be read off a single line item: the cache hit rate and the time distribution of traffic decide the final bill. Repricing data and formulas So how do you use them, performance-wise? V4 Pro is better for planning, hard reasoning, and review; V4 Flash is better for execution, bulk file edits, and high concurrency. In the independent, small-sample Revelo Code Index, V4 Flash's aggregate pass rate across four coding tasks came out above V4 Pro — which does not mean Flash is smarter on every problem, only that it is faster and cheaper, and that the test harness, model versions, and context settings all affect the outcome. Revelo Code Index My take: DeepSeek is still a good “cheap execution layer,” but it is not the right thing to run every long-context agent on without watching the bill. If you can schedule off-peak work, hit cache reliably, or reach it through OpenCode Go, the value is still excellent; otherwise GLM Lite, OpenCode Go, or even MiniMax Plus may be easier to budget with.

GLM: after the price rise, the Coding Plan sells quota and a local experience

GLM's change was not a simple multiplier on the monthly fee; the tiers, models, and quotas were redesigned. The current mainland-China version is Lite ¥49, Pro ¥149, Max ¥469; legacy-user migrations, first-purchase discounts, and overseas Z.AI pricing should not be compared in the same breath. Every plan supports GLM-5.3, GLM-5-Turbo, and GLM-4.7, and calls to older models are routed to the new versions automatically. Official plan description GLM uses a rolling 5-hour quota plus a weekly quota. The part that is easier to overlook is peak hours: on weekdays between 14:00 and 18:00 (UTC+8) credits are deducted at the base rate, while off-peak deductions are 50%. Lite's “reference weekly token figure” is therefore not a fixed number but a 43–87M range, and Pro and Max show the same 2× band. When a plan runs out it does not automatically fall back to your regular API balance — you wait for the next 5-hour window to reset. This design has three advantages for developers in China: payment in CNY, domestic network access, and support for Chinese-language repository tooling. The downside is equally clear: it only works inside the vendor's designated tools, and you cannot hand a Coding Plan key to your own SaaS as a general API key. If you touch one small-to-medium repository a day, Lite is enough; running several agents continuously or working in a large monolith makes Pro the more sensible choice; Max only makes economic sense if you exhaust both the 5-hour and the weekly quota every day. On performance, GLM-5.2's public results are still the best baseline for judging GLM-5.3: Zhipu's own report puts Terminal-Bench 2.1 at 81.0, close to Opus 4.8's 85.0 — but that is a vendor-run test and cannot be read as a third-party leaderboard. In Revelo's independent small sample, GLM-5.2 posts an aggregate pass rate of about 30.8%, below Kimi K3, at a much lower cost. GLM's value is not “first place on every metric”; it is the overall balance of Chinese-language requirement comprehension, tool integration, and a fixed monthly fee.

Kimi: the most complete feature set, but the quota pool matters more than the price

Kimi's four tiers have grown from a plain chat membership into a workspace subscription: Moderato $19, Allegretto $39, Allegro $99, Vivace $199. Agents, PPT, deep research, Kimi Code, Work, Claw, and the rest all draw from a single quota pool; K2.6 is free for all users in chat and does not consume quota, while K3 is available from Moderato upward and 1M context only unlocks at Allegretto. Kimi plan overview So Kimi's “60/150/360/720 agent credits” are a normalization of typical tasks, not a fixed request count. A complex research report, a web deployment, and a coding-agent run can consume wildly different token volumes; Kimi Claw's cloud host also quietly draws on part of the quota. If you mostly chat, free K2.6 already covers a lot; if you switch between research, documents, and code, Allegretto at $39 is the more balanced tier; buying Vivace purely for code usually works out worse than OpenCode Go or Claude Code. Kimi K3's hallmarks are its very large scale, 1M context, and long-horizon engineering tasks. In independent tests its aggregate pass rate and cost both land in the middle: stronger than GLM-5.2 and MiniMax M3, but on the slow side; the vendor's own comparisons concede that a different harness changes the result. It suits long context, Chinese-language knowledge work, and projects that need multi-turn agent memory, not users who only care how many requests they get per dollar.

MiniMax: M3's quota is large, but multimodal features drink from the same pool

In the MiniMax M3 era the Token Plan is Plus $20, Max $50, Ultra $120. The official reference figures based on M3 usage are roughly 1.7B, 5.1B, and 12.5B tokens per month, and text, images, speech, and music share one quota pool; Max and Ultra also include daily video generation, with agent concurrency of roughly 3–4, 4–5, and 6–7. Official MiniMax monthly plans MiniMax's headline token count far exceeds most chat memberships, but you should not read it as “12.5 billion tokens to call at will”: the vendor also imposes a rolling 5-hour window and a weekly window, throttles dynamically during peak hours, and does not roll over unused quota; a single request from a complex agent also includes multiple rounds of tool calls. In other words, Plus is very cheap if you only write code, but when code, images, speech, and music share the plan, the quota disappears faster than you would expect. M3's strengths are long context, agent concurrency, and integrated multimodality. In Revelo's tests its coding pass rate trails Kimi K3, GLM-5.2, and DeepSeek Flash, but its per-run cost is lower; it is closer to a “high-throughput execution model” than a first choice for every hard planning task. For people building OpenClaw, automation scripts, and multimodal prototypes, Max is the sweeter spot than Ultra; Ultra is only worth it when you genuinely need both the concurrency and the video quota.

OpenCode: not a model, but a channel that decouples price from model

OpenCode has two product lines that are easy to confuse:
  1. OpenCode Zen is a model gateway billed per request or per token; the vendor tests model-and-provider combinations, and you can also bring your own key from OpenAI, Anthropic, or a Chinese vendor.
  2. OpenCode Go is a $10/month subscription ($5 for the first month) that gives a set of open models a unified usage cap: $12 of value per 5 hours, $30 per week, $60 per month. Official Go quota description
Go's usage is not “one quota per model.” The official examples show, within 5 hours, about 880 GLM-5.2 requests, about 110 Kimi K3, about 3,200 MiniMax M3, and about 31,650 DeepSeek V4 Flash. Expensive models get fewer requests because the quota is normalized to each model's dollar cost; once you hit the cap you can switch to a free model or top up your Zen balance and keep paying. That explains why OpenCode Go is such good value: for $10 you buy a switchable basket of models, stable agent integration, and a single billing ceiling, rather than unlimited access to one model. If you mostly write code and are willing to split planning models from execution models, Go is the top recommendation in this comparison; if you just want one Chinese model, buying GLM Lite directly is simpler.

ChatGPT and Claude Opus: you are paying for product completeness, not per-token pricing

ChatGPT

ChatGPT Plus is $20/month; Pro comes in $100 (5× Plus usage) and $200 (20× usage). The core value of Plus/Pro is the GPT-5.6 family, Codex, deep research, file and image tools, projects and tasks — not a published API token bundle. OpenAI's Pro tier notes ChatGPT pricing page If every day you write emails, read PDFs, build spreadsheets, look things up, generate images, and occasionally fix code, Plus is excellent value overall. If your main job is running Codex continuously, Plus's advanced-tool limits will bite sooner than web chat will, and Pro at $100 is the better upgrade; $200 only makes sense when parallel projects, long deep-research sessions, and heavy Codex use are all part of your day. ChatGPT computes limits separately per product, per model, and per time window, so “unlimited text chat” does not imply unlimited Codex.

Claude Opus

Opus here is a model, not a separate subscription. Claude Pro is $20/month ($17 equivalent annually), Max 5× is $100, Max 20× is $200; Max's 5×/20× refers to per-5-hour-session capacity relative to Pro, and there is also a weekly cap. Official Claude Max notes Claude plan comparison In terms of product experience, Claude Code's terminal workflow, code review, cross-file edits, and long-task stability remain Opus's strengths. In Revelo's 80-task aggregate test, Claude Opus 5 passes 57.1% and GPT-5.6 Sol 51.2%; but Opus averages about $6.44 per task against roughly $2.05 for GPT and $1.12 for Kimi K3. The result says Opus's edge is success rate and reliability, not cheapness. Revelo Code Index methodology and results If you only occasionally ask Claude for help, Pro at $20 already gives you access to Opus; if it is your primary agent every day, Max 5× at $100 is the lowest tier that keeps you from getting cut off. Claude API pricing for Opus 5 is the standard $5 input and $25 output per million tokens — a separate ledger from the monthly subscription, and the two should not be mixed. Anthropic model pricing

Buying advice by scenario

1. Students, personal blogs, light coding

Start with GLM Lite at ¥49 or OpenCode Go at $5 for the first month. The former suits the domestic environment and Chinese repositories; the latter suits trying out several models. DeepSeek's API works as a no-monthly-fee supplement — set a balance cap and cache your repeated prefixes.

2. Coding every day, budget capped around ¥150

Go with OpenCode Go plus a DeepSeek Flash/GLM split between execution and planning. Use GLM or Kimi for planning and Flash/MiniMax for execution; do not throw every request at Kimi K3 or DeepSeek Pro. If you would rather not juggle model switching, take GLM Pro at ¥149.

3. Beyond code: research, spreadsheets, images, and meeting materials

ChatGPT Plus at $20 is the pick. Its value is tool integration and cross-task context, not first place on a single coding benchmark. Google AI Pro is also $19.99/month and suits people already deep in Gmail, Docs, Drive, and NotebookLM, but availability and payment methods in mainland China need to be confirmed separately. Official Google AI Pro notes

4. Large repositories, complex refactors, code review

Start with Claude Pro at $20 and upgrade to Max 5× at $100 once you use it heavily; if you would rather split planning, execution, and review across different models, pay-as-you-go OpenCode Zen is more flexible. Opus's per-run success rate is worth paying for on high-risk code, but it should not be your high-throughput batch model.

5. Multimodality and agent concurrency

MiniMax Plus/Max is the recommendation. It puts M3, images, speech, music, and video into one quota pool, which suits prototyping and automation; if 90% of your work is plain text code, MiniMax's multimodal perks turn into a “free gift” you pay for and never use.

Final ranking: by value, not by raw strength

  1. Pure coding, low budget: OpenCode Go
  2. Chinese-language coding in China: GLM Lite / Pro
  3. General productivity: ChatGPT Plus
  4. Reliability on complex code: Claude Pro, then Max 5× once you are a heavy user
  5. Multimodal agents: MiniMax Plus / Max
  6. Long documents and Chinese research: Kimi Allegretto
  7. Batch API calls: DeepSeek Flash off-peak; use Pro only when a task demands it
In one sentence: after August 18, the optimal answer is not “buy the single strongest product” — it is to cap your agent spend with a fixed monthly fee, execute with cheap models, and use GLM/Kimi/ChatGPT/Opus for planning and review. DeepSeek's price increase is a reminder for everyone: caching, peak versus off-peak windows, context length, and tool calls are the variables that actually drive your AI bill.
