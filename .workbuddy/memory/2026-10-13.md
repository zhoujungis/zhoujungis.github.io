## 螺旋填数（算法系列第 35 篇，端到端发布完成）

- **一个状态机 + mode 参数喂两个动画**（`spiralSteps.js` 的 `mode: 'rdlu' | 'drul'`，`spiral.js` 导出 `mountSpiral` / `mountSpiralCcw`，另开 3 行别名模块 `spiralCcw.js` 给 viz-shot）—— 换皮类变体的标准打法（LC 102/103/199 同款）。
  - `algo-viz--spiral`：右、下、左、上（面经里的"逆时针"）
  - `algo-viz--spiralccw`：下、右、上、左（几何上的真逆时针）
- **文章立意 = 口径对齐**：「右下上左」从左上角出发几何上是**顺时针**，却被大量面经叫作逆时针；真逆时针是「下右上左」。**方阵下两者恰好互为转置**（3×3 验证 true），**非方阵不成立**（2×3 就不同）—— 所以"逆时针=顺时针转置"只在方阵碰巧对。
- **守卫 bug 的精确边界（脚本实测，推翻了面经的笼统说法）**：漏掉第三、第四条边的 `top <= bottom` / `left <= right` 守卫，**只在剩余区域退化成单行/单列时才炸**（1×3 → `[[5,4,3]]`、3×1 → `[[1],[4],[3]]`，后来的数覆盖先前的）；**2×3 / 3×2 / 2×5 / 5×2 漏守卫也全对**。很多面经说"非方阵会错"是不准确的。回归测试直接钉 `1 x N` / `N x 1`。
