## 规定时间内到达终点的最小花费 LC 1928（算法系列第 38 篇，端到端发布完成）

- **题面**：`edges[i] = [x, y, time]` 是无向边（只有时间、没有花费）；另有 `passingFees[]`，**每次经过一座城市都付费（含起点 0 与终点 n-1）**；求 0 → n-1 在 ≤ maxTime 内最小通行费，不可达返回 -1。官方示例 edges=[[0,1,10],[1,2,10],[2,5,10],[0,3,1],[3,4,10],[4,5,15]]、fees=[5,1,2,20,20,3]：maxTime 30 → 11（0→1→2→5，30 分）；29 → 48（0→3→4→5，26 分）；25 → -1。**⚠️ 贵路边耗时是 1/10/15（合计 26）**，不是表面看到的便宜路立刻可用。
- **正解**：`dp[t][v] = 恰好在 t 时刻到达 v 的最小通行费`；`dp[0][0] = passingFees[0]`；按 t 正序松弛 `dp[t+et][u] = min(…, dp[t][v] + passingFees[u])`；答案 = `min over t ≤ maxTime of dp[t][n-1]`；O(maxTime·E)。**反直觉点：一维 dp[v] 会漏解——时间不可压缩，所以「时刻」必须进状态**；本质是「便宜但超时」vs「贵但达标」的取舍。备选正解：小顶堆 Dijkstra on (cost, t, v)。

## KMP 求 next 数组（算法系列第 39 篇，端到端发布完成）

- **题面**：求 `p = "abacaba"` 的 next 数组。本文用**前缀函数**（最长相等**真**前后缀，`next[0] = 0` 由定义天然成立）→ **`[0,0,1,0,1,2,3]`**；另一种（严蔚敏《数据结构》风格）首项记 `-1`、`next[i]` 描述 `p[0..i-1]` → `[-1,0,0,1,0,1,2]`；关系 **`B = [-1] + A[0..n-2]`**（整体右移一格）。**面试第一坑：开口先问用哪种定义**，报错了就是零分。
- **机制**：**自己跟自己匹配**。`j` 双身份 = 「已匹配前缀长度」也是「下一个要和 `p[i]` 比的下标」；不变量进入比较前恒有 `p[0..j-1] == p[i-j..i-1]`；失配 `while` 沿 **`next[j-1]`** 回退（不是 `next[j]`、不是 `if`），相等则 `j += 1`，收尾 `next[i] = j`。**均摊 O(n)**：`j` 每步至多 +1，回退只是把自增值还回去。匹配段 `i` 永不回退 → `O(n + m)`。
- **默认动画一实测**（`algo-viz--kmp`）：16 帧 = init + 14 + done；next=[0,0,1,0,1,2,3]；**comparisons=7、retreats=1**；唯一回退在 `i = 3`（`p[3]='c'` vs `p[1]='b'`，`j` 1 → `next[0] = 0`，后再比 `p[0]='a'` 仍不等才定 0）。
- **默认动画二实测**（`algo-viz--kmpmatch`）：18 帧 = init + 13 compare + 2 retreat + found + done；text="abababacaba"、p="abacaba"、**index=4**；kmpComparisons=**13** vs bruteComparisons=**17**（暴力逐起点 s=0:4、s=1:1、s=2:4、s=3:1、s=4:7）；两次回退在 `i=3` 与 `i=5`（都是 `'b'` 撞 `p[3]='c'` 后退到 `next[2]=1`，再用 `p[1]='b'` 接住同一个 `text[i]`）。
